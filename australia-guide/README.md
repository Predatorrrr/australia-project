# AUSTRALIA PROJECT

Interface immersive premium (React + Vite) pour préparer un projet australien.

## Lancer en local

```bash
cd australia-project
npm install
npm run dev
```

Ouvrir l’URL affichée par Vite (souvent `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Contenu

Neuf intercalaires navigables (Accueil → Visa → … → Vie pratique). Les libellés et CTAs sont en français. La liste des chapitres est centralisée dans `src/data/sections.ts` pour renommer ou ajouter facilement.
